# Password Strength Analyzer

A beginner-friendly Python cybersecurity project that evaluates user-entered passwords based on length, character complexity, common-password patterns, and repeated characters.

## Features
- Checks password length
- Checks uppercase and lowercase letters
- Checks numbers and special characters
- Detects common passwords
- Detects repeated characters
- Produces a score out of 6
- Classifies passwords as Weak, Medium, or Strong
- Provides suggestions for stronger passwords

## Requirements
- Python 3.x
- No external libraries required

## Run
```bash
python password_strength_analyzer.py
```

## Security note
This project is for educational purposes. Do not enter a password that you currently use for a real account.
